# 🚀 JavaScript Mini Projects

This repository contains **5 beginner-friendly JavaScript projects** that I built while learning **HTML, CSS, and JavaScript**. These projects helped me understand DOM manipulation, events, functions, loops, conditions, and basic JavaScript concepts.

## 📌 Projects

### 1. 📝 To-Do List

A simple To-Do application where users can:

* ➕ Add tasks
* ❌ Delete tasks
* 🧹 Manage daily tasks easily

**Tech Used:** HTML, CSS, JavaScript

---

### 2. 🧮 Calculator

A basic calculator that performs:

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🗑️ Clear functionality

**Tech Used:** HTML, CSS, JavaScript

---

### 3. ❌⭕ Tic Tac Toe Game

A two-player Tic Tac Toe game featuring:

* 🎮 Player X & O turns
* 🏆 Winner detection
* 🔄 Reset game option

**Tech Used:** HTML, CSS, JavaScript

---

### 4. 🕒 Digital Clock

A live digital clock that:

* ⏰ Displays the current time
* 🔄 Updates every second
* 📱 Responsive design

**Tech Used:** HTML, CSS, JavaScript

---

### 5. 🔐 Password Generator

A random password generator that:

* 🔒 Creates secure passwords
* 🎲 Generates random characters
* ⚡ Creates a new password with one click

**Tech Used:** HTML, CSS, JavaScript
